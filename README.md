# Event UI

React components for event pages, discovery, and previews, inspired by Luma.

[Demo](https://ui.wtw.quest) · [Component docs](packages/react/README.md) · [Abel on X](https://x.com/abelasfaw0)

## Run locally

Requires Node.js 24.

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run build
npm test
npm run verify:package
```
